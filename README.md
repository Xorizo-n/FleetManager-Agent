# FleetManager Agent

FleetManager Agent — агент для Windows, который работает на компьютерах и взаимодействует с [FleetManager Server](https://github.com/Xorizo-n/FleetManager-Server). Он периодически собирает сведения об устройствах, передаёт их серверу и помогает выполнять задачи централизованного администрирования.

## Инвентаризация и состояние

Агент сообщает серверу о своей работе и передаёт сведения об операционной системе, модели и серийном номере компьютера, процессоре, памяти, сетевых адаптерах и дисках. Для дисков собираются данные об объёме и свободном месте, для сетевых адаптеров — сведения, необходимые в том числе для пробуждения по сети.

Также агент собирает список установленного программного обеспечения и состав рабочего места: материнскую плату, BIOS, модули памяти, физические диски, видеокарты, мониторы, клавиатуры, мыши и другие USB-устройства. Сервер использует эти сведения для инвентаризации и отслеживания изменений оборудования.

Отдельно собираются сведения об активации Windows и Office. Состояние агента и результаты синхронизации доступны в его интерфейсе и на сервере.

## Связь и удалённое управление

Агент поддерживает подключение компьютера к серверу и проверяет состояние компонентов, необходимых для удалённого администрирования. Установщик также может подготовить компьютер к подключению через удалённый рабочий стол и пробуждению по сети. При необходимости агент помогает сохранить связь с сервером при использовании VPN.

## Обои и обновления

Агент применяет назначенные сервером изображения рабочего стола и экрана блокировки. Когда назначение снимается, он возвращает исходные настройки.

Сервер отслеживает версии агентов и может запускать их обновление. Агент также способен получить и установить обновление через собственное соединение с сервером.

## Интерфейс

Значок в области уведомлений показывает состояние агента и позволяет запустить синхронизацию вручную. В панели управления можно посмотреть сведения о компьютере, состояние службы, время синхронизации и журнал, а также настроить подключение к серверу.
